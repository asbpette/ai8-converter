Installing Ghostscript

AI8 Converter needs Ghostscript to read EPS and PostScript files. PDF, AI, SVG and DXF files convert without it.

AI8 Converter will not install anything for you. It never downloads or runs software behind your back. Follow the steps for your system below, and do them yourself, so you can see exactly what is being installed and where it comes from.

What Ghostscript is, and why it is separate

Ghostscript is a PostScript and PDF interpreter made by Artifex Software, Inc. It is not part of AI8 Converter and is not bundled with it. AI8 Converter runs it as a separate program and contains none of its code.

It is published under the GNU Affero General Public License v3. That licence has conditions AI8 Converter's MIT licence does not, which is why you install it yourself and receive it directly from Artifex under their terms rather than ours.

macOS

Artifex does not publish a ready-made macOS build, so use a package manager.

With Homebrew (recommended)

If you do not have Homebrew, install it first from brew.sh. Then open Terminal and run:

brew install ghostscript

This installs to /opt/homebrew/bin/gs on Apple Silicon, or /usr/local/bin/gs on Intel Macs. AI8 Converter looks in both.

With MacPorts

sudo port install ghostscript

This installs to /opt/local/bin/gs, which AI8 Converter also checks.

Windows

The installer from Artifex (recommended)

  1. Open ghostscript.com/releases/gsdnld.html.
  2. Download the 64-bit installer under Ghostscript AGPL Release, named something like gs10080w64.exe.
  3. Run it and accept the defaults. It installs to C:\Program Files\gs\, where AI8 Converter looks.

Or with the helper script

The AI8 Converter folder contains Install Ghostscript.cmd. Double-click it and it will fetch Artifex's installer for you, check that Artifex's signature is on the download before running it, and then start Artifex's own installer so you accept their licence. It uses Chocolatey instead if you already have it.

It is an ordinary text file: open it in Notepad first if you want to see exactly what it does.

Or with Chocolatey

choco install ghostscript

Ghostscript is not available through the Windows Package Manager (winget).

Linux

Install your distribution's package:

sudo apt install ghostscript      # Debian, Ubuntu
sudo dnf install ghostscript      # Fedora
sudo pacman -S ghostscript        # Arch

Afterwards

AI8 Converter checks for Ghostscript every couple of seconds while it is missing, so the Ghostscript line turns to found on its own shortly after the install finishes. There is no need to restart it, though the Re-detect button forces an immediate check.

If it is still not found

Use the Browse… button on the Ghostscript line to point AI8 Converter straight at the program:

  • Windows: C:\Program Files\gs\gsVERSION\bin\gswin64c.exe
  • macOS and Linux: gs — run which gs in a terminal to find its path

You can also set the AI8_GHOSTSCRIPT environment variable to the full path of the program, which overrides everything else. On the command line, ai8conv --gs PATH does the same for one run.
