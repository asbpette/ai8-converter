Converts EPS, PS, PDF, AI, SVG and DXF vector files to the Adobe Illustrator 8 format, for vinyl cutters, plotters, engravers, RIPs and older design software.

Free and open source under the MIT Licence.
github.com/asbpette/ai8-converter

Reading EPS and PostScript needs Ghostscript, which is not included. It is separate software by Artifex Software, Inc. under the GNU AGPL v3, run as a separate program. See Installing Ghostscript.html inside this app.

Built with Rust, egui and resvg. Licences for all bundled open source libraries are in THIRD-PARTY-NOTICES.txt inside this app.
